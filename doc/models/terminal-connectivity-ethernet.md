
# Terminal Connectivity Ethernet

## Structure

`TerminalConnectivityEthernet`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `IpAddress` | `string` | Optional | The terminal's ethernet IP address. |
| `LinkNegotiation` | `string` | Optional | The ethernet link negotiation that the terminal uses. |
| `MacAddress` | `string` | Optional | The terminal's ethernet MAC address. |
