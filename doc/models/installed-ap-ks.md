
# Installed Ap Ks

## Structure

`InstalledApKs`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `ConfirmationDate` | `DateTime?` | Optional | The date and time when the app was installed. |
| `PackageName` | `string` | Optional | The package name of the app. |
| `VersionName` | `string` | Optional | The version name of the app. |
