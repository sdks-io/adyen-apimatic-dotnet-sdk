
# Home Screen Settings 1

Settings for the home screen.

## Structure

`HomeScreenSettings1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `HideNavigationBar` | `bool?` | Optional | Hide/show the navigation bar. |
| `ShowPaymentsMenu` | `bool?` | Optional | Show/hide the payments menu. |
| `ShowSettingsMenu` | `bool?` | Optional | Show/hide the settings menu. |

## Example (as JSON)

```json
{
  "hideNavigationBar": false,
  "showPaymentsMenu": false,
  "showSettingsMenu": false
}
```
